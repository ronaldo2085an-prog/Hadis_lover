# Love ATM — دستگاه خودپرداز عاشق
وب‌اپ استاتیک (HTML/CSS/JS)، بدون بک‌اند و بدون جمع‌آوری هیچ داده‌ای.

## اجرا
فایل `index.html` را در مرورگر باز کن. (فونت Vazirmatn از Google Fonts لود می‌شود؛ آفلاین از Tahoma/Arial استفاده می‌شود.)

## انتشار رایگان
پوشه را در Netlify Drop (app.netlify.com/drop) بکش، یا در GitHub Pages / Cloudflare Pages منتشر کن.

## ویرایش
- رنگ‌ها و فونت: بالای `css/style.css` (بخش `:root`)
- متن‌ها: `index.html`؛ پیام‌های دکمه «نه»: آرایه `MESSAGES` در `js/app.js`
- قلب بزرگ: `js/heart-animation.js` (تعداد قلب‌ها در `layers`، رنگ‌ها در `PINKS`)
